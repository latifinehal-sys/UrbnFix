# UrbnFix

UrbnFix is an open-source, responsive mobile and tablet application designed to connect users with local freelance service workers. Built with a focus on a clean, modern UI/UX, the app allows users to easily browse services, filter by location, and contact professionals directly.

## Features

* **Modern UI/UX:** A minimalist, touch-optimized design that provides a seamless single-column feed on mobile devices and expands into a clean grid layout on tablets.
* **Location-Based Discovery:** Users can easily filter and find freelance workers operating in their specific city or neighborhood.
* **Professional Service Cards:** Browse workers via visual cards that highlight their specific service category, showcase their work, and display their years of experience.
* **Direct Contact:** Reach out to workers directly from the app using integrated phone numbers and optional email links.
* **Quick Category Filtering:** Sort through different professions (e.g., Plumbers, Electricians, Cleaners, Designers) using a clean horizontal scroll menu.
